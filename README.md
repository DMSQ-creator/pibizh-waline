# Pi中文网 Waline 评论系统

## ⚡ 快速部署（只需2步）

### 第1步：一键部署到 Vercel
点击下方按钮：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/DMSQ-creator/pibizh-waline)

### 第2步：添加数据库（Vercel 内一键完成）
1. 进入项目 → 顶部 **Storage** 标签
2. 点 **Create Database**
3. 选择 **Neon Postgres** → 选 Singapore → **Create**
4. 环境变量自动注入 ✅
5. 点 **Deployments** → 最新部署 → **⋯** → **Redeploy**

搞定！🎉
