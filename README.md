# Pi中文网 Waline 评论系统

## 部署步骤

1. 点击下方按钮一键部署到 Vercel
2. 注册 LeanCloud 国际版 (https://console.leancloud.app) 免费账号
3. 在 LeanCloud 创建应用，获取 AppID、AppKey、MasterKey
4. 在 Vercel 项目设置中填入环境变量
5. 完成！

## 支持的登录方式
- 匿名评论（填昵称即可）
- 邮箱注册
- GitHub
- Google  
- Facebook
- Twitter
- 微信（需配置）
- 更多...
